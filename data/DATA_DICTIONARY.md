# Data dictionary

## Synthetic_HbA1c_v3_CVI1.6_CVA0.8.xlsx
Measurement-level synthetic cohort (2,000 simulated patients; 8,286 HbA1c measurements) generated by
`scripts/make_sim_v3.py` (seed 20261007) with the same column schema as the LIS workbook, so that
`scripts/build_cohort.py` processes it unchanged. Injected truth: CVI = 1.6% in both phenotypes, CVA = 0.8%,
no covariate effect on dispersion; see `results/SIM_v3_truth.json` and Supplemental Methods 1 of the article.
